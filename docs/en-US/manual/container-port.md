# Container Port Access

## Mapped Ports

After mapping ports inside the container when creating it, you can access it through `http://ip:port`.
By default, the panel will automatically obtain the IP address based on the current browser address or the current server endpoint's connection parameters.

If you need to configure an IP address or specify it as a domain, modify it through [Configure Server Access Address](/manual/system-env#server-url).

## Bind Domain

To bind domain access for containers, please see [Domain Forwarding](/manual/container-domain).
