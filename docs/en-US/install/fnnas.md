## Upload Deployment

Because there may be some delay in the FNNAS App Store review process, you can install the latest version of DPanel by uploading the fpk package through **Manual Installation** in the FNNAS App Store.

![fnnas-1](https://cdn.w7.cc/dpanel/fnnas-1.png?t=1)
