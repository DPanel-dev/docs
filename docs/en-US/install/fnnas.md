# Install from the FNNAS App Store

DPanel is available in the official FNNAS App Store. You can install it directly from the store.

## Install from the App Store

![DPanel in the FNNAS App Store](https://cdn.w7.cc/dpanel/fnnas-2.png?t=2)

### Install manually

If a new DPanel release is still under review, download the `.fpk` package for your NAS and upload it using **Manual Installation** in the FNNAS App Store.

![Manual installation in the FNNAS App Store](https://cdn.w7.cc/dpanel/fnnas-1.png?t=1)

### Offline packages

- [amd64](https://github.com/donknap/dpanel/releases/latest/download/dpanel-amd64.fpk)
- [arm64](https://github.com/donknap/dpanel/releases/latest/download/dpanel-arm64.fpk)
- [More releases](https://github.com/donknap/dpanel/releases)

## Third-party app stores

The following stores also offer DPanel and sync updates as they are released:

- [FnDepot — third-party app repository for fnOS](https://github.com/DPanel-dev/FnDepot)
- [Moo — third-party app center for fnOS](https://github.com/Blue-Mink/moo)

## Manage an FNNAS device as a remote host

Instead of installing DPanel on your NAS, you can manage it from an existing DPanel instance. Enable SSH on the NAS, then add it as an SSH host in [Multi-Server Management](../manual/system-env#ssh).
