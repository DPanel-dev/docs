## Image Addresses

:::tip
Choose the appropriate image address based on your version requirements and network environment.
:::

### Based on Alpine Images

:::code-group

```shell [Standard Edition]
dpanel/dpanel:latest
```

```shell [Lite Edition]
dpanel/dpanel:lite
```

```shell [Alibaba Cloud Standard Edition]
registry.cn-hangzhou.aliyuncs.com/dpanel/dpanel:latest
```

```shell [Alibaba Cloud Lite Edition]
registry.cn-hangzhou.aliyuncs.com/dpanel/dpanel:lite
```
:::

### Based on Debian Images

:::code-group

```shell [Standard Edition]
dpanel/dpanel:latest-debian
```

```shell [Lite Edition]
dpanel/dpanel:lite-debian
```

```shell [Alibaba Cloud Standard Edition]
registry.cn-hangzhou.aliyuncs.com/dpanel/dpanel:latest-debian
```

```shell [Alibaba Cloud Lite Edition]
registry.cn-hangzhou.aliyuncs.com/dpanel/dpanel:lite-debian
```
