# 使用第三方系统域名转发

Lite 版需借助其他第三方系统的反向代理功能绑定域名转发。

## 通过容器 Bridge 网络的 IP 转发

通过容器在 Bridge 网络的 IP 进行转发时，创建容器时可不映射容器内的端口，直接通过容器在 Bridge 网络的 IP 进行转发。

但 IP 不是固定的，随着容器的停止再启动 IP 可能会变化。

```shell
location / {
    proxy_pass http://[容器在Bridge网络的IP]:[容器内端口];
}
```

## 通过映射端口进行转发

将容器的内部端口映射到宿主机端口时，可通过 `127.0.0.1` 进行转发：

```shell
location / {
    proxy_pass http://127.0.0.1:[容器映射端口];
}
```
