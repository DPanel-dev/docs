# 更新 DPanel 面板

DPanel 支持在面板内更新自身。更新时，面板会调用 DPanel 安装程序，由安装程序读取当前实例的配置、拉取新镜像并重新创建面板容器。

更新过程会保留当前面板的容器名称、端口、挂载目录和运行配置。请确保容器的 `/dpanel` 目录仍挂载到原来的存储卷或宿主机路径，面板数据不会因容器重建而丢失。

## 在面板中更新

进入【系统】->【系统更新】，检查新版本后执行更新即可。

![upgrade](https://cdn.w7.cc/dpanel/system-upgrade.png)

面板本身不会在当前容器进程内直接替换程序，而是启动独立的安装程序完成后续更新。安装程序会停止并重新创建面板容器，因此更新期间面板会暂时无法访问。等待容器重新启动后，刷新页面即可。

:::warning 更新前请注意
- 建议先通过【系统】->【面板设置】->【用量与备份】备份面板数据。
- 更新期间不要手动停止或删除安装程序相关的容器或进程。
- 如更新后页面显示异常，请强制刷新浏览器以清除旧的静态文件缓存。
:::

## 使用安装程序手动更新

面板内更新与手动运行安装程序使用的是同一套更新流程。如果面板无法访问，或面板内更新失败，可在宿主机上通过【[DPanel 安装程序](/install/shell)】选择对应实例进行更新。

## 使用 Docker Compose 更新

如果面板由 Docker Compose 管理，也可以在 Compose 项目目录中执行：

```shell
docker compose up -d --pull always
```

更新前请确认 Compose 配置仍挂载原有的 `/dpanel` 数据目录。
