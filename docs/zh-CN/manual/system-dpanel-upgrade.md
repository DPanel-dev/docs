# 更新 DPanel 面板

> 面板无法自我更新，更新操作需在宿主机上执行。

更新面板即重新拉取镜像并重建 dpanel 容器。
操作中需确保重建时容器的 `/dpanel` 目录仍挂载到之前的存储卷或路径。

### 通过一键脚本更新

运行一键脚本时，如指定的容器名称已存在，脚本会执行更新逻辑。详见【[一键安装脚本](/install/shell)】。

### 使用 docker run 命令更新

可通过【系统】->【系统更新】菜单获取面板更新脚本命令。

更新脚本会自动获取 dpanel 容器的安装参数并生成更新命令。

### 使用 docker compose 更新

```
docker compose up -d --pull always
```

### 通过创建面板分身更新

复制面板容器并勾选【绑定随机端口】创建面板分身，打开分身后升级原始面板容器。升级完成后，在原始面板中删除分身容器。
