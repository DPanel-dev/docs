# 使用飞牛应用商店部署

DPanel 已经正式上架了飞牛官方应用商店，你可以直接在飞牛商店安装 DPanel。

## 应用商店部署

![fnnas-1](https://cdn.w7.cc/dpanel/fnnas-2.png?t=2)

### 手动部署

由于飞牛应用上架审核有一定的延迟性，你可以通过在飞牛应用商店中通过 **手动安装** 上传 fpk 包安装最新版的 DPanel。

![fnnas-1](https://cdn.w7.cc/dpanel/fnnas-1.png?t=1)

## 将飞牛做为远程主机管理

除了在应用商店安装外，你还可以把通过 [多服务端管理](/manual/system-env) 将飞牛做为远程主机来管理。
在添加前同样需要先 `开启 SSH` 功能。

使用 `SSH` 的方式添加飞牛主机即可。
