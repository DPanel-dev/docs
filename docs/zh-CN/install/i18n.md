# 扩展语言包 <Badge type="tip" text="DPanel Version >= 1.9.1" />

## 内置语言文件

面板默认内置了中、日、英三种语言，语言包文件位于 [asset/static/i18n](https://github.com/donknap/dpanel/tree/master/asset/static/i18n) 目录中。

## 扩展语言文件

::: tip
扩展或修改语言包文件后需重新打包面板程序或提交 PR 打包发布在主程序中。
:::

除内置的语言包外，面板支持自定义扩展以下语言。自定义扩展语言包时，新建对应的语言包 json 文件并完善内容即可。

| 名称 | 代码 | 文件名 |
| ------------- | :----------- | :---- |
| 阿拉伯语 | ar-EG | /asset/static/i18n/ar-EG.json |
| 西班牙语 | es-ES | /asset/static/i18n/es-ES.json |
| 法语 | fr-FR | /asset/static/i18n/fr-FR.json |
| 韩语 | ko-KR | /asset/static/i18n/ko-KR.json |
| 马来语 | ms-MY | /asset/static/i18n/ms-MY.json |
| 葡萄牙语 | pt-BR | /asset/static/i18n/pt-BR.json |
| 俄语 | ru-RU | /asset/static/i18n/ru-RU.json |
| 土耳其语 | tr-TR | /asset/static/i18n/tr-TR.json |
| 繁体中文 | zh-TW | /asset/static/i18n/zh-TW.json |
